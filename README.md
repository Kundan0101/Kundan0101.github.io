# AI/ML Portfolio Starter

This is a simple, single-page portfolio starter for an M.Tech AI/ML student.

## Before sharing it
1. Open `index.html` in VS Code.
2. Replace every placeholder such as `YOUR NAME`, institute, graduation year, email and LinkedIn URL.
3. Remove project placeholders until you have real projects. Never claim unfinished work as completed.
4. Add GitHub repository links only after you upload your actual code.

## Publish free with GitHub Pages
1. Create a GitHub account at https://github.com/ using an email you can access.
2. Verify your email.
3. Click **New repository** and name it `yourusername.github.io` (replace `yourusername` with your GitHub username).
4. Set it to **Public**.
5. Upload `index.html` to the repository's root and commit the change.
6. Open **Settings → Pages**. If needed, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
7. Wait for deployment. Your site address will be `https://yourusername.github.io/`.

The published link is your portfolio URL. It may take a few minutes to become available.
